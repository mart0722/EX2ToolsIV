# EX2ToolsIV 2.3.0

Дата: 25.11.2026  
APK: `EX2ToolsIV-2.3.0.apk`  
versionCode: 120  
SHA-256: `71979AD0FC1F1E19D3432C3C0E74EE24B1966F0986370E68CDE9E1D69D68E05F`

## Взято из PR #3 (nicola1223)

- Установка и откат патча штатного `GeelyAutoKeyServer` из приложения.
- Назначения четырёх кнопок руля: климат, подогревы, режим езды, рекуперация.
- Режим назначенных действий с lease/heartbeat и автоматическим возвратом
  штатного управления через 15 секунд.
- Восстановление режима езды и рекуперации после включения зажигания,
  в том числе когда экран оставался включённым.
- Виджеты спидометра 3×3 и 4×4, масштаб Chrome до 300%.
- Секунды в виджетах часов.
- Запоминание «Скрыть все» для карточек Flyme Auto.
- Исправление дворников при запирании: потерянный neutral, дублирующийся lock,
  проверка P/скорости/зажигания, команда без чтения текущего положения.
- Более аккуратная установка APK через `PackageInstaller`.

## Добавлено нами

- `AppWidgetBindActivity` — обработчик стандартного `APPWIDGET_BIND`.
  Сторонние лаунчеры (Nova и другие) могут добавлять виджеты без ADB
  и без `appwidget grantbind`.
- Мультиверсионный `SteeringPatch`:
  - выбор патча по `versionCode` + SHA-256 установленного keyserver;
  - `26030420` — 1114/1111;
  - `26052410` — 1121;
  - отдельный backup для каждой версии;
  - откат из backup или bundled-оригинала, если он есть;
  - неподдерживаемая версия → «unsupported», без установки.
- Собран патч для `26030420` и добавлен патч `26052410` от PR.
- Кроссплатформенная сборка патча (`build_patch.py`): Windows `.bat`,
  подпись через keystore, проверка ожидаемого SHA-256 оригинала.
- Обновлены release/USB-пакеты и документация.

## Примечания

- Патчи лежат в `build/steering/` и не коммитятся в git.
- Оригинальные keyserver APK не вкладываются в публичный APK. Backup создаётся
  при установке; для offline-восстановления после очистки данных нужен оригинал.
- Для 1111/1114 используется keyserver `26030420`. Если APK на 1111 отличается
  по SHA-256, нужна отдельная запись в таблице.
