# Климат кнопками руля — IHU629G

Патч поддерживает только исходный GeelyAutoKeyServer версии 26052410:
SHA-256 `62b94ffa72e5e4bb81fce4882750530089cab94fcb286c1fcea288f71781fa73`.
Проверен разбор событий на ГУ с прошивкой SW0E22H0530H112100000.

В отдельном разделе «Кнопки руля» включается «Управление климатом».
Переключатель по умолчанию выключен. Голос и доступ к микрофону не требуются.
Для него нужен APK с патчем keyserver, одного EX2ToolsIV недостаточно.

- Одиночное короткое нажатие голосовой кнопки: обычный запуск/остановка голоса
  с задержкой 400 мс для распознавания второго нажатия.
- Два коротких нажатия с интервалом до 400 мс: включить/выключить климат.
- Громкость +/−: температура +/− 1 °C.
- Следующий/предыдущий трек: скорость вентилятора +/− 1.
- Через 15 секунд без управляющих нажатий: обычный режим.
- В обычном режиме обработчики штатного сервиса работают как прежде.
- При остановке приложения lease сбрасывается, при аварийном завершении
  перехват новых нажатий прекращается максимум через 3 секунды.
- Завершение уже перехваченного нажатия поглощается даже после таймаута,
  чтобы отпускание не вызвало неожиданное переключение трека.
- Долгое нажатие голосовой кнопки остаётся в штатном обработчике.

Запись температуры/вентилятора выполняется через ClimateController в отдельном
потоке. Настройки lease используют Settings.Global и монотонное время.
Мост принимает только четыре известные кнопки. Broadcast ограничен пакетом
EX2ToolsIV и системным permission WRITE_SECURE_SETTINGS с обеих сторон.

## Сборка и проверки

Нужны JDK 17, Android SDK 34 / Build Tools 34.0.0, Apktool 3.0.3.
Исходный APK и ключи не включаются в git.

```sh
python3 tools/steering-patch/test_bridge.py
python3 tools/steering-patch/test_mode.py
python3 tools/steering-patch/build_patch.py \
  --original /path/GeelyAutoKeyServer-original.apk \
  --apktool /path/apktool_3.0.3.jar \
  --sdk /path/android-sdk \
  --java-home /path/jdk17/Contents/Home \
  --key /path/platform.pk8 --cert /path/platform.x509.pem \
  --output build/steering/GeelyAutoKeyServer-climate.apk
```

Сборщик проверяет хэш исходного APK, добавляет вызов моста в единственную
точку диспетчеризации и сохраняет исходные ресурсы/манифест побайтно.
Подпись должна совпадать с сертификатом исходного сервиса.

## Установка и откат

Исходный сервис сохранён локально в
`build/steering-backup/GeelyAutoKeyServer-original.apk`.
Обновления устанавливаются поверх существующих APK, без записи /system:

```sh
adb -s IP:5555 install -r app/build/outputs/apk/release/EX2ToolsIV-2.0.8-steering-climate.apk
adb -s IP:5555 install -r build/steering/GeelyAutoKeyServer-climate.apk
adb -s IP:5555 shell am start -n com.ex2tools.iv/.MainActivity
```

Для немедленного прекращения перехвата:

```sh
adb -s IP:5555 shell settings put global ex2_climate_expiry 0
```

Для восстановления оригинального кода сервиса:

```sh
adb -s IP:5555 install -r build/steering-backup/GeelyAutoKeyServer-original.apk
```

До включения переключателя необходимо проверить, что обновлённый сервис
запускается и обычные кнопки работают. Затем проверить двойное нажатие,
по одному изменению температуры/вентилятора, повторное двойное нажатие
и автоматический выход по таймауту. JVM-тесты не заменяют проверку на ГУ.
